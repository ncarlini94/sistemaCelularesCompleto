# Administrador de Líneas Celulares

¡Bienvenido/a a nuestro repositorio de GitHub para el Administrador de Líneas Celulares! Este proyecto está desarrollado utilizando React para el frontend y Node.js para el backend.

## Descripción

El Administrador de Líneas Celulares es una aplicación web diseñada para gestionar de manera eficiente las líneas celulares dentro de una organización. Permite administrar jurisdicciones, reparticiones, funcionarios y las líneas móviles asociadas a cada uno de ellos. Además, incluye funcionalidades como historial de cambios, importación de archivos y más.

## Características principales

- **Gestión de jurisdicciones:** Permite crear, editar y eliminar jurisdicciones dentro de la organización.
- **Gestión de reparticiones:** Facilita la administración de las distintas reparticiones dentro de cada jurisdicción.
- **Gestión de funcionarios:** Permite mantener un registro de los funcionarios, así como de sus datos personales y asignaciones.
- **Gestión de líneas móviles:** Permite asignar y gestionar las líneas móviles de cada funcionario.
- **Historial de cambios:** Registra todas las modificaciones realizadas en la aplicación para un seguimiento detallado.
- **Importación de archivos:** Permite importar datos de líneas celulares desde archivos externos para una rápida actualización de la base de datos.

## Tecnologías utilizadas

- **Frontend:** React
- **Backend:** Node.js
- **Base de datos:** MySQL
